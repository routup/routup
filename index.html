v6 HTTP routing on Request & Response

Match the route.
Return the response.

A minimalistic HTTP framework built on Web-standard Request and Response. Handlers return values, middleware awaits event.next(), and the same app runs on Node.js, Bun, Deno and Cloudflare Workers.

// what's in the box

Six pieces. One small core.

Everything else is a tree-shakeable helper or a plugin you opt into.

  • 01

    Web Standards

    app.fetch() takes a Web Request; handlers return anything toResponse() converts.

    await app.fetch(new Request(url))
  • 02

    Runtime agnostic

    One import, routup, runs on Node.js, Bun, Deno and Cloudflare Workers; routup/<runtime> selects a specific adapter.

    // default entry
import { serve } from 'routup';
// Bun's native server, Bun.serve
import { serve } from 'routup/bun';
  • 03

    Return-based handlers

    Return a value; content type, ETag and 304 are handled.

    (event) => ({ id: 1 })
  • 04

    Onion middleware

    await event.next() wraps every handler downstream.

    const res = await event.next();
return res;
  • 05

    Plugins

    An object with name and install(app); version and singleton are optional.

    app.use({ name: 'auth', install(app) {} })
  • 06

    Tree-shakeable helpers

    getRequestIP, sendRedirect, … import only what you use.

    import { getRequestIP } from 'routup'

From zero to first request

Install the package, define a handler, serve the app.

Quickstart →
import { App, defineCoreHandler, serve } from 'routup'; const app = new App(); app.get('/users/:id', defineCoreHandler(    (event) => ({ id: Number(event.params.id) }))); serve(app, { port: 3000 });
routup/node

Drop in alongside Express.

Wrap Node middleware with fromNodeMiddleware(), or turn the app into a (req, res) handler with toNodeHandler().

Express compatibility →
server.ts
import cors from 'cors';import express from 'express';import { App, fromNodeMiddleware, toNodeHandler } from 'routup/node'; const app = new App(); app.use(fromNodeMiddleware(cors()));       // reuse Express middleware express()    .use('/v2', toNodeHandler(app))        // or mount routup inside Express    .listen(3000);
