# Reference: h3js/h3

Not a dependency. h3 v2 has the same shape as routup (srvx server layer, return-based handlers, `(event, next)` onion middleware, tree-shakeable helpers), so its features and security fixes are a checklist for routup.

## Behavioural differences

Checked against `src/` on 2026-11-22:

- **Path normalization:** `/api//admin`, `//api/admin`, `/%61dmin/1` and `/admin%2F1` get 404 and never skip a guard, on all three routers. h3 normalizes needless escapes and matches them; routup refuses them.
- **Method case:** h3 compares methods case-insensitively. routup sends a lowercase `patch` to 404, which follows RFC 9110 (methods are case-sensitive). Kept on purpose.
- **HEAD:** h3 omits the body on its default error responses. routup's fallbacks, and GET handlers answering HEAD, keep the body in the `Response`. Node.js strips it before sending.
